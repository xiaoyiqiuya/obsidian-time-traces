# 🐾 时迹 · Time Traces

> Obsidian 插件 · 柳比歇夫时间管理法 · v0.1.0

---

## 核心理念

**脚步计时法**：不同于传统计时器「先开始→后结束」，时迹采用**做完一件事后再记录**的设计。每次点击记录时，插件自动计算距上次记录所经过的时间，形成无缝时间链。这让脑中始终有一个"时间沙漏"在滴答，自然产生做事的动力。

---

## 打开方式（无需快捷键）

| 方式 | 操作 |
|------|------|
| 🐾 **侧边栏图标** | 点脚印图标 → 打开面板，底部三 Tab 切换 |
| 👆 **底部 Tab 栏** | 🐾计时 · 🌳项目 · 📊统计，点一下切换 |

打开后，界面底部有三个 Tab：

```
┌──────────────────────────┐
│                          │
│     当前面板内容          │
│   (计时 / 项目 / 统计)    │
│                          │
├──────────────────────────┤
│  🐾 计时 │ 🌳 项目 │ 📊 统计 │  ← 底部栏
└──────────────────────────┘
```

> 💡 也可 `Ctrl+P` → 搜索「时光」用命令面板。推荐给「快速记录」设快捷键 `Alt+J`。

## 功能指南

### 🐾 脚步计时 —— 日常时间记录

1. 打开计时面板（点脚印图标）
2. 顶部显示「距上次记录已过 X 小时 Y 分钟」——这就是你下次记录时会写入的时长
3. 点击任意项目按钮 → 这段时长就被记录到该项目下
4. 计时器归零，重新开始计算

**新建项目后点击**：输入新项目名称 → 按回车 → 自动记录并创建项目。

### 🌳 人生之树 —— 项目层级管理

```
考研（8h）
├── 中医综合（5h）
│   ├── 方剂学（3h）
│   └── 中药学（2h）
└── 英语（3h）
```

- **打开**：`Ctrl+P` →「时迹: 打开人生之树」
- **点击节点**：记录时间到该项目
- **右键节点**：添加子项目 / 编辑 / 删除
- **展开/折叠**：点击 ▶/▼ 箭头
- 子项目时间自动汇总到父项目

### 📋 时间日志 —— 今日回顾

计时面板下半部分展示今日所有记录，按时间倒序，颜色标记帮你一眼看出时间分配。

### ⚙️ 设置页（情境颜色）

`设置 → 第三方插件 → 时迹 → 齿轮图标`

---

## 🎨 情境颜色系统 —— 怎么用？

情境（Situation）是对项目类型的**一级分类标签**，用颜色帮你一眼看出时间花在哪。

### 默认配色 & 含义

| 情境 | 颜色 | 色块 | 适用于 |
|------|------|------|--------|
| 🟢 **生活** | `#4CAF50` | 绿色 | 吃饭、睡觉、洗漱、通勤、家务 |
| 🟡 **学习** | `#FFC107` | 琥珀 | 看书、听课、复习、考研、背单词 |
| 🔵 **运动** | `#2196F3` | 蓝色 | 跑步、健身、跳绳、瑜伽 |
| 🟣 **工作** | `#9C27B0` | 紫色 | 上班、任务、会议、邮件 |
| 🟠 **备课** | `#FF9800` | 橙色 | 家教备课、课件制作 |
| 🔴 **娱乐** | `#F44336` | 红色 | 游戏、刷视频、刷社交媒体 |
| ⚪ **默认** | `#9E9E9E` | 灰色 | 未分类的杂项 |

### 如何使用

1. **创建项目时选择情境**：新建项目 → 在编辑弹窗中选择一个情境 → 项目自动获得该情境的颜色
2. **颜色出现在**：
   - 快捷项目按钮的左边框
   - 项目树节点前的小圆点
   - 时间日志中的项目名
3. **自定义颜色**：`设置 → 时迹 → 情境颜色` → 点击色块修改

### 最佳实践（来自时迹资深用户）

> "事项数只用两只手——最多十来个一级分类就够了。记录最'泛泛'的内容，不记录细节。"
>
> "以打卡的方式忠实记录活动，以粗线条日记的方式进行每日回顾。"

| 操作 | 路径 |
|------|------|
| 导出备份 | `设置 → 时迹 → 导出 JSON` |
| 恢复备份 | `设置 → 时迹 → 选择文件` |
| 清除数据 | `设置 → 时迹 → 清除`（不可恢复！） |

数据纯本地存储，不联网，不上传。

## 🔄 跨设备同步（配合 remotely-save）

时迹的数据默认存在 `~/.time-is-gold/data.json`（系统目录），切换 Vault 不会丢失。

但如果你用 **remotely-save** 等插件同步 Vault 到多设备，可以切换为 Vault 内存储：

1. `设置 → 第三方插件 → 时迹 → 齿轮图标`
2. 在「🔄 数据同步」区域，将**数据存储位置**切换为 **Vault 内 (.time-is-gold/)**
3. 数据会保存到 Vault 根目录的 `.time-is-gold/data.json`
4. remotely-save 会把这个文件夹同步到所有设备
5. 切换时旧数据自动迁移，不会丢失

> 📱 **效果**：在手机上记录的时间，到电脑上 reload 后就能看到。

## 📱 iPad / iPhone 安装

**无需手动安装。** 只要你在桌面端启用了 remotely-save 同步：

1. iPad 上打开 Obsidian → 同一个 Vault（remotely-save 会同步）
2. `设置 → 第三方插件` → 关闭安全模式
3. 找到「时迹」→ 开启

插件文件在 `.obsidian/plugins/time-is-gold/` 下，remotely-save 会自动同步到 iPad。

> ⚠️ 数据存储位置在移动端会自动使用 **Vault 内** 模式（无需手动设置），确保记录在 iPad 和桌面间同步。
